# আমার মুক্তাগাছা

মুক্তাগাছাবাসীদের জন্য কমিউনিটি পোর্টাল — এলাকার খবর, জরুরি হটলাইন, সেবা ডিরেক্টরি, ইতিহাস ও ইভেন্ট, সব একসাথে।

**লাইভ সাইট:** https://amarmuktagacha.github.io/

## কী কী আছে

- 📰 **খবর** — এলাকার খবর ও আপডেট
- ☎️ **জরুরি হটলাইন** — জাতীয় (999, 333, ইত্যাদি) ও স্থানীয় নাম্বার, ট্যাপ করলেই কল হয়
- 🏥 **সেবা ডিরেক্টরি** — ডাক্তার, হাসপাতাল, ব্যবসা প্রতিষ্ঠান
- 🏛️ **ইতিহাস** — নামের উৎপত্তি, জমিদারবাড়ি, শিব মন্দির, মন্ডা
- 📅 **ইভেন্ট** — এলাকার অনুষ্ঠান ও ঘোষণা
- ✍️ **তথ্য জমা দাও** — যে কেউ ইমেইলের মাধ্যমে খবর/ইভেন্ট/সেবার তথ্য পাঠাতে পারবে

সম্পূর্ণ **static** সাইট — কোনো ব্যাকএন্ড বা লগইন নেই। "তথ্য জমা দাও" মেইল আকারে আসে, যাচাই করে ম্যানুয়ালি সাইটে যোগ করতে হয়।

## টেক স্ট্যাক

React 19 + TypeScript + Vite + Tailwind CSS v4 + React Router (HashRouter)

## লোকাল ডেভেলপমেন্ট (Termux)

```bash
git clone https://github.com/amarmuktagacha/amarmuktagacha.github.io.git
cd amarmuktagacha.github.io
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

`main` ব্রাঞ্চে push করলেই `.github/workflows/deploy.yml` স্বয়ংক্রিয়ভাবে build করে GitHub Pages-এ ডিপ্লয় করে দেয়। প্রথমবার শুধু repo-র **Settings → Pages → Source** এ **"GitHub Actions"** সিলেক্ট করে দিতে হবে।

## কনটেন্ট যোগ করা

`src/data/` ফোল্ডারের ফাইলগুলো এডিট করে নতুন খবর/ইভেন্ট/সেবা/হটলাইন যোগ করা যায় — প্রতিটা ফাইলের উপরে উদাহরণ দেওয়া আছে:
- `news.ts` — খবর
- `events.ts` — ইভেন্ট
- `services.ts` — সেবা ডিরেক্টরি
- `hotlines.ts` — জরুরি নাম্বার (স্থানীয় নাম্বারগুলোর `number` ফিল্ড খালি আছে, বসিয়ে দাও)
- `history.ts` — ইতিহাস সেকশন
